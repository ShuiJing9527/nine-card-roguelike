# 追击逐段递减修订（2026-10-26）

本次按用户明确确认覆盖规则书旧版“原生总系数×15%”规则。

当前公式：每条追击的第k段系数 = 1号位主技能单段基础系数 × 起始倍率（Rate=1）× 本槽位保留率^k，k从1开始。槽位1～5的保留率分别为90%、80%、70%、60%、50%；段数仍取当前槽位。每个同名词条独立重新起算，后一个词条不接续前一个词条的尾段。

例：主技能基础伤害100，3号位追击3段，基础伤害70→49→34.3。五卡破风箭基础系数350%，3号位追击系数为245%→171.5%→120.05%；五卡连射仍为7个60%的原生段，3号位追击为42%→29.4%→20.58%，原生七箭不求和作追击基准。

递减作用于未取整的基础系数，不使用上一次实际扣血、护盾吸收或屏幕数字。各段独立计算实际目标防御、穿透、增伤、命中、暴击、闪避和格挡；死亡转火不重置衰减，不转移单段过量伤害。词条属性加值及护盾消耗加值仍只分配给原生攻击。反击生成的追击使用同一递减方法。

基础系数递减不保证屏幕数字严格递减：暴击、转火后的防御、逐段四舍五入及原有最低1点规则仍会影响最终数字。

已同步：BattleEngine的正式结算、反击、预览、逐段日志；BattleCatalog.asset的词条说明及Rate；InitialRules.json和Tools/extract_rules.py的重建配置。Tools/RulesSnapshot.json保留原始规则书提取记录，未伪造原书文字。旧验证报告中的伤害数值属于旧版公式。

编辑入口：Assets/Data/BattleCatalog.asset → Traits → 追击（Rate=1为起始倍率）；Rules → Pursuit Retention（五个槽位每段保留率）。其他技能数值未调整。
