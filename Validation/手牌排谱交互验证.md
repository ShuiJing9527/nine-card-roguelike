# 手牌与排谱交互验证（2026-10-26）

手牌现在由“原始九卡 ID 减去当前排谱 ID”派生，只有排谱列表可修改。同一实体卡不会同时显示在手牌和排谱；手牌按原始九卡顺序收拢。

- 点击手牌排入；槽位的左右箭头只交换已有 ID；“移除”归还原卡；“清空”全部归还。
- 确认成功后锁定排谱和目标，保留槽位供悬停查看。播放结束仍保持锁定；下一次正常玩家行动开始时清空并恢复九张手牌，反击不触发重置。
- 重试仍按原有约定恢复当时的测试配置与排谱，重建手牌互斥显示；提交后下一次正常玩家行动再重置。
- 移动前关闭提示框、取消抬起/缩放与排列脉冲、清除 UI 选中对象；重新绑定实体卡 ID、战斗实例和绑定代次。旧回调不能复活提示框或操作新卡。现有交互使用点击与槽位箭头，没有新增拖拽系统。
- 原始九卡外观对象保留在 Scene/Prefab 中；运行时仅隐藏已排入卡面与点击区，剩余手牌按已保存的九卡中心、间距和扇形参数收拢。重试不把收拢后的坐标误记为原始布局。

主要修改：`BattleDemo.cs`、`BattleDemo.Layout.cs`、`HandCardInteraction.cs`。未改战斗公式、技能数值、规则数据或重铸词条配置。
